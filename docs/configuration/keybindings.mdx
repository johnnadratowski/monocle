---
title: "Keybindings"
description: "Override any monocle keybinding with your preferred keys."
---

Monocle lets you remap any action to a key of your choice. Add a `keybindings` object to your [config file](/configuration/config-file) and map action names to key strings.

## How to configure

Add entries to the `keybindings` object in your config file:

```json
{
  "keybindings": {
    "quit": "Q",
    "submit": "ctrl+s",
    "scroll_down": "ctrl+j"
  }
}
```

Each key in the object is an action name; the value is the key string to bind. Only include the actions you want to override — unspecified actions keep their defaults.

<Tip>
  Press `H` in monocle to see the current effective keybindings, including any overrides you've applied.
</Tip>

## Available actions

| Action | Default key | Description |
|--------|-------------|-------------|
| `up` | `k` | Move cursor up |
| `down` | `j` | Move cursor down |
| `top` | `g` | Jump to top |
| `bottom` | `G` | Jump to bottom |
| `half_up` | `ctrl+u` | Scroll up half a page |
| `half_down` | `ctrl+d` | Scroll down half a page |
| `prev_file` | `[` | Previous diff chunk in the diff pane; previous file otherwise |
| `next_file` | `]` | Next diff chunk in the diff pane; next file otherwise |
| `select` | `enter` | Focus diff pane / toggle directory |
| `pane_left` | `ctrl+h` | Move pane focus left; at monocle's edge, moves the tmux pane |
| `pane_down` | `ctrl+j` | Move pane focus down; at monocle's edge, moves the tmux pane |
| `pane_up` | `ctrl+k` | Move pane focus up; at monocle's edge, moves the tmux pane |
| `pane_right` | `ctrl+l` | Move pane focus right; at monocle's edge, moves the tmux pane |
| `focus_swap` | `tab` | Switch pane focus |
| `toggle_sidebar` | `;` | Toggle sidebar visibility |
| `scroll_down` | `J` | Scroll diff down |
| `scroll_up` | `K` | Scroll diff up |
| `scroll_left` | — | Scroll diff left (any pane; lowercase `h` always scrolls the focused diff) |
| `scroll_right` | `L` | Scroll diff right |
| `scroll_home` | `0` | Scroll to column 0 |
| `scroll_first_char` | `^` | Scroll to first non-space character |
| `scroll_end` | `$` | Scroll to end of line |
| `wrap` | `w` | Toggle line wrapping |
| `toggle_diff` | `t` | Cycle diff style (unified / split / file) |
| `toggle_full_diff` | `a` | Toggle full-file diff (whole file vs. changed lines) |
| `search_backward` | `?` | Search the diff backward (when the diff pane is focused) |
| `search_next` | `n` | Jump to the next search match |
| `search_prev` | `N` | Jump to the previous search match |
| `prev_mark` | `<` | Jump to the previous comment or annotation |
| `next_mark` | `>` | Jump to the next comment or annotation |
| `block_match` | `%` | Jump between the current block's start and end |
| `block_up` | `(` | Jump out one level, to the enclosing block's opening line |
| `block_top` | `)` | Jump out to the outermost enclosing block |
| `toggle_overlays` | `O` | Hide / show inline comments + annotations |
| `hide_comments` | `#` | Cycle source-code comment-only lines: dim → hide → show |
| `open_doc_ref` | `o` | Open / cycle an annotation's doc links in the doc pane (closes after the last) |
| `tree_mode` | `f` | Cycle flat / tree / grouped view |
| `collapse_all` | `z` | Collapse all tree nodes |
| `expand_all` | `e` | Expand all tree nodes |
| `prev_section` | `{` | Go to previous file (any pane) |
| `next_section` | `}` | Go to next file (any pane) |
| `filter_reviewed` | `/` | Sidebar: cycle filter (all → unreviewed → reviewed). Diff pane: start a forward search |
| `comment` | `c` | Add comment at cursor |
| `file_comment` | `C` | Add file-level comment |
| `answer` | `A` | Add a comment at the cursor already typed as an answer |
| `question` | `Q` | Add a comment at the cursor already typed as a question |
| `suggest` | `s` | Suggest edit at cursor |
| `visual` | `v` | Start visual (multi-line) selection |
| `yank_line` | `y` | Yank the current line (or visual selection) to the clipboard |
| `reviewed` | `r` | Toggle file reviewed |
| `submit` | `S` | Submit review |
| `pause` | `P` | Pause the agent |
| `clear_review` | `D` | Clear all comments, plans, added files, and reviewed states |
| `dismiss_artifact` | `x` | Dismiss the focused artifact, or remove the focused added file, from the sidebar (confirm required) |
| `toggle_focus_mode` | `F` | Toggle focus mode (hide sidebar, enable wrap) |
| `jump_back` | `ctrl+o` | Back to the position you jumped from (vim `ctrl+o`) |
| `jump_forward` | `ctrl+i` | Forward again through the jump list (vim `ctrl+i`) |
| `open_in_editor` | `ctrl+g` | Open current text in `$VISUAL`/`$EDITOR` |
| `open_in_editor_takeover` | `ctrl+shift+g` | Like `open_in_editor`, but always takes over the screen (ignores `editor_mode`) |
| `open_in_markdown_viewer` | `ctrl+p` | Open the current artifact/file in an external viewer: markdown/text → `markdown_viewer` (default `glow -p`), media (image/video/audio) → `media_viewer` (default Google Chrome) |
| `open_terminal` | `ctrl+t` | Open a terminal at the current file's directory — takes over Monocle's screen by default, or a tmux split/window when `editor_mode` is a `tmux_*` mode |
| `open_terminal_takeover` | `ctrl+shift+t` | Like `open_terminal`, but always takes over the screen (ignores `editor_mode`) |
| `shell_command` | `!` | Run a shell command on the current file: opens a prompt pre-filled with the file path (cursor at the start) |
| `base_ref` | `b` | Change base ref |
| `artifact_versions` | `B` | Browse artifact version history and diff against a previous version |
| `cycle_layout` | `T` | Cycle layout (auto / side-by-side / stacked) |
| `refresh` | `R` | Force reload files |
| `help` | `H` | Show keybindings overlay |
| `quit` | `q` | Quit monocle |
| `command_mode` | `:` | Enter command mode |
| `wizard_advance` | `enter` | Advance to the next step in the register wizard |
| `wizard_back` | `shift+tab` | Go back to the previous step in the register wizard |
| `wizard_toggle` | `space` | Toggle the current option in the register wizard |

<Note>
  Modal keys — Enter, Esc, and Tab inside overlays — are not configurable.
</Note>
